## Forge
1.  Description
A ' is a workstation in 7 Days to Die that is used for the crafting of advanced weapons, tools, armor, ammunition, material blocks, and other essential items needed for survival in the post-apocalyptic world.

    1.  Overview
Many items can be smelted in a Forge, a process which extracts the useful raw materials and stores them in the Forge for later use in Crafting. Many recipes either require a Forge or an item produced using a Forge in order to be crafted.

Usable Forges can be found throughout the game world, including within Trader outposts. Alternately, a Forge can be crafted and then placed for use. Player-owned forges within the bounds of the player's Land Claim Block can be picked up by holding down the activate key (default 'E') and selecting the Take option on the radial menu. Only a fully-repaired Forge that is empty (with the exception of less than 10 of each smelted material) can be picked up.

    1.  Uses
A Forge can be used for Smelting as well as Crafting. Both activities require Combustible fuel. The Forge can smelt items at the same time it is being used to craft finished products, with no increase in fuel demand; a forge that is turned on will do both simultaneously.

Note that once a Forge is turned on, it will continue burning fuel until it is manually turned off or all the fuel is expended; it does not turn off by itself if there are no current smelting or crafting happening.

    1.  Smelting
Smelting in 7 Days to Die refers to the process of heating up items in a forge to extract the useful raw materials. Each smeltable item will result in one type of smelted forge material: Iron (Forge), Brass (Forge), Lead (Forge), Sand (Forge), Stone (Forge), or Clay (Forge). Once the smelted materials are created in the Forge, they remain in the forge inventory, ready to be used for crafting items.

Smelting is done by first activating the Forge to open the Forge Menu.

Smeltable items are placed into one or both of the 2 smelting slots on the righthand side of the Forge Menu screen. Combustible fuel is placed into any of the 3 fuel slots. The Forge can then be turned on. While the  is running, items in both smelting slots will simultaneously and gradually be consumed, adding the materials to be stored inside the Forge as noted in the smelted materials list. Each forge material is limited to 30,000 units each. Items will not be smelted if the material that it would produce has already reached its limit.

Any materials stored in the Forge cannot be directly removed. Instead, the stored materials must be crafted back into items that can be picked up into inventory. Each type of stored material has a Forge recipe to create the basic resource item version of that material. If the Forge is destroyed, all the materials that have been smelted into it will be lost.

## Gun Safe
1.  Description
A Gun Safe is a type of secure storage that just like a Desk Safe or a Wall Safe can be locked and unlocked by the player. They can often be found in the attics of houses in towns or on the ground floor inside buildings, usually secured behind Iron Bars and they can contain some very useful items and weapons. Crafting a Gun Safe is easy but due to the crafting recipe requiring multiple steel ingots it is very expensive on resources. A destroyed  Gun Safe will not drop anything and the contents will be lost. A Gun Safe cannot be dismantled, scrapped, melted in a forge or used as source of combustible fuel.

When found in the wild, a Gun Safe must receive 5000 points of damage before the lock "layer" is broken and it becomes accessible. Effective tools are Pickaxes and TNT. When crafted by the player, they can be locked and unlocked as described below. Lockpicks can also be used to open them, less tediously, but it has a random luck element.

Gun Safes crafted by the player do not contain loot. As of Alpha 21, Gun Safes crafted by the player can be different colors by using the Shape Menu.
    1.  Usage
Built in to a Gun Safe is a security function which offers the player three options in relation to the control of the Gun Safe, Pressing and holding down the E key while looking at the Gun Safe will bring up three icons showing each of the three options, these are explained below.
-  Left Icon - This is a keypad icon and is used to set up a password for the Gun Safe, simply move your cursor over the icon and release the E key to bring up the password input box. Using the password input box you can type any password you like and set it by clicking the green set button, or press the red cancel button to exit the menu and cancel the password input. Once you have set a password for the Gun Safe you will be able to open and close it at will, but it will remain locked for other players. Any player that knows the password will be able to open this Gun Safe. You may select any password between 1-4 characters in length and it may contain any combination of letters, numbers, or symbols.
-  Centre Icon - This is a doorway icon, moving your cursor over this icon and releasing the E key with either open or close the Gun Safe depending in which state it was in when you pushed down the E button.
-  Right Icon - This is a padlock icon and represents the Gun Safe lock, move your cursor over the icon and release the E key to toggle the Gun Safe between being either locked or unlocked. A Gun Safe that is locked without a password can only be opened by the player that locked it.

## Land Claim Block
1.  Description
The  (LCB) provides extra protection for a 41x41 (adjustable in map/server settings) horizontally-based region. In both Single and Multi-player modes, it enables picking up your work stations and electric devices within the governed area. The player who placed the land claim block can hold "E" while facing the object they wish to pick up and will be presented with an option to take it. If you destroy the land claim block, the area it owned with extra border zone is then forbidden for claiming again. (This could be for a period of time, still testing.)

While there is no limit on the number of LCBs a player can place in the world, only three LCBs may be active at a time. Placing a new LCB will cause an old LCB to go inactive and be reduced to 1 durability. The protection provided by the old LCB will disappear.

A  is active as long as the player who placed it is in the game. Once a player leaves the game there is a configurable delay to when the LCB considers them offline. This defaults to the instant they leave, but may be increased in map/server settings. Once a player is offline then the LCB uses the offline protection multiplier. By default this is the same as the online protection multiplier, 4x less damage. This can also be adjusted in settings. The land claim duration setting controls how long a LCB will continue to provide offline protection for before going inactive, by default this is 7 days.

The  should prevent all Point of Interest Zombies from respawning within its area. Furthermore, if its protected area includes a Point of Interest then it should prevent Trader jobs from selecting that POI as an quest location. This allows players to take over POI structures.

This does not prevent open world or horde zombie spawns, only POI zombie spawns are suppressed. For example if a player were to go into the Forest, place an LCB, surround the area in a 1-block wide by 3-block high wall, and leave the area for a bit, they might see a zombie or two within the undamaged wall the next time they return. In order to suppress open world zombie spawns in the area the player must replace or cover the Forest Ground or any surface block not placed by a player, with player obtained blocks such as Building Blocks or Concrete Blocks. However, there may be special rules for certain entities such as vultures that will still allow them to spawn. More testing is required.

    1.  Protection Zone
As stated, the LCB creates a protection zone. The size of the zone can be changed via server settings. The default setting is a 41 x 41 area that extends infinitely in both directions above and below the LCB, creating a column that extends the full height of the map. All blocks inside the protection zone receive the durability multiplier, which can be changed via server settings. By default, the damage multiplier is 4.

1.  Overview
A ' is a craft-able Door that has the ability to be locked by the player. It is crafted using Wood. A  can be upgraded to an Iron Door (which can be further upgraded to a Steel Door). The door will slowly break down as it takes damage. There are 5 total stages of damage with the last one being completely destroyed with just the frame left standing (which can be repaired without needing to craft a new door). The last 2 stages before that, a hole will appear in the door which can be used to attack through the door. But watch out, Zombies can use that hole too!

    1.  Usage

A  offers three security feature options, in relation to the player's control of the Door. Holding down the 'E' key, while looking at the , will bring up the following three icons:
-   Left Icon - This is a keypad icon and is used to set up a password for the Door, moving the cursor over the icon and releasing the E key will bring up the password input box. Using the password input box the player can type any password they like and set it by clicking the green set button, or press the red cancel button to exit the menu and cancel the password input. Once the player has set a password they will have to enter it into the Door to be able to open it, this only needs to be done the first time the player uses the Door. Any player that knows the door code will be able to open this Door.

-   Center Icon - This is a doorway icon, moving the cursor over this icon and releasing the E key will either open or close the Door depending on which state it was in when the player pushed down the E button.

-   Right Icon - This is a padlock icon and represents the Door lock, moving the cursor over the icon and releasing the E key will toggle the Door between being either locked or unlocked. A Door that is locked without a password can only be opened by the player that locked it.

## Workbench
1.  Description
The ' is an additional crafting queue for the player and will require crafting one to benefit from the additional recipes it provides. Using ingredients held in the player's Inventory, the workbench can craft items that the player cannot normally craft from their backpack as well as items that are only available on the . This can enable a player to craft multiple items simultaneously, using the workbench as well as their backpack. Players can craft and walk away as the  completes the task independently.

Unusable Workbenches can be found throughout the game world, including within Trader outposts. Alternately, a Workbench can be crafted and then placed for use. Player-owned workbenches within the bounds of the player's Land Claim Block can be picked up by holding down the activate key (default 'E') and selecting the Take option on the radial menu. Only a fully-repaired Workbench that is empty can be picked up.

Destroyed Workbench cannot be crafted from or repaired to be utilized and are good only for scrapping with a Wrench or being left alone to gather resources from its storage when the area resets (assuming chunk reset is turned on).
