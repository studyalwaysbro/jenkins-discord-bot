## Steady Arm (left)
Type = Robot Limbs

Steady Arm (left) is a Robot Limb, and a replacement for a lost left arm. This is the only robot limb that boosts Crossbows, so it is ideal for rangers.

Since there are only left-handed Steady Arms, and only right-handed Thief's Arms, these two arms synergize well together. They both increase Dexterity, and do not lower any Statistics that the other arm raises.

## Thief's Arm (right)
Type = Robot Limbs

Thief's Arm (right) is a Robot Limb, and a replacement for a lost right arm. As the name suggests, it is ideal for use by thieves, as it raises Lockpicking, Thievery, and Dexterity. There are only right-handed Thief's Arms, which makes them synergize well with the exclusively left-handed Steady Arm.
